# 閲覧履歴の接続

GitHub Pagesの「共有設定」→「閲覧履歴の連携」から設定用のキーを表示する。
両方のキーをCloudflare WorkerのSecretに登録する。設定値はGitHubや公開ファイルに置かない。

CloudflareのGitHub連携で、このリポジトリの `view-log` をルートに指定する。
構成ファイルは `wrangler.toml`、デプロイコマンドは `npx wrangler deploy`。
CLIを使う場合も、このディレクトリを起点にする。

公開WorkerのHTTPSオリジンを、Pagesの `VIEW_LOG_ENDPOINT` とCSPの `connect-src` に追加する。
コードとスタイルのSHA-256ハッシュを更新してから公開し、テスト用の閲覧で記録・取得を確認する。

閲覧画面が初めて表示されたときに記録する。日時はサーバーが決定し、IPはCloudflareの受信ヘッダーから取得する。
同じページ内の移動や自動更新は数えない。以前から閲覧コードを記憶した端末は、共有リンクを開き直した次の閲覧から計測される。
履歴は30日間。画面には直近500件の日時を表示し、回数は30日間の合計で表示する。
